Module motion 

Source
Expand description

Retargeted mocap clips (AMASS / SONIC → G1 joint space), used as an upper-body DISTURBANCE source for the balance curriculum: while the command is “stand”, the held (non-action) joints replay a random window of a random clip, so the legs learn to keep the pelvis level under realistic arm + waist motion instead of a frozen home pose. The policy never observes the upper body — the moving mass is an unmodeled perturbation, exactly like a human carrying/gesturing.

File format: the SONIC CSV export. Header row Frame,root_translateX..Z,root_rotateX..Z,<joint>_dof,...; angles are DEGREES (root translation is centimetres — both ignored here). Columns are matched to the caller’s joint names as <name>_dof, so the same file drives any subset of the model’s joints: legs are simply never requested, and clip columns the model doesn’t have (the 29dof-agile G1 drops wrist pitch/yaw) are ignored. A REQUESTED joint missing from the file is a hard error — silent zero-filling would quietly turn a dance clip into a statue.
