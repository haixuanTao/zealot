pub fn env_views(&mut self) -> Vec<EnvHistView<'_>>

Split into per-env mutable views (disjoint slices), so a batch of envs can push+stack CONCURRENTLY. The serial push_stacked loop measured ~12 ms/step at 4096 envs (H=5, dim=53) — all in one thread; the caller feeds these views to rayon instead.
