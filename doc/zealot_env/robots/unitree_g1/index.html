The Unitree G1 humanoid, as a legs-only 12-DOF walking platform.

Model: assets/robots/unitree_g1_12dof.xml, generated by scripts/convert_unitree_biped.py from the OFFICIAL legs-only model (unitree_rl_gym/resources/robots/g1_description/g1_12dof.{urdf,xml}, also mirrored into the unitree_ros checkout) — the pelvis carries the fused upper-body mass (17.73 of 32.11 kg), and the converter normalizes every hinge axis to local +Z (zealot’s joint-builder convention; the G1 model uses X for roll, Y for pitch, Z for yaw).

Numbers and their provenance:

  • PD gains / action scale / default pose: unitree_rl_gym G1RoughCfg (legged_gym/envs/g1/g1_config.py) — the config Unitree trains and deploys their public G1 walking policy with: kp hip 100 / knee 150 / ankle 40, kd 2/2/2/4/2, action_scale 0.25, home pose hip_pitch −0.1, knee 0.3, ankle_pitch −0.2.
  • Effort / velocity / position limits: the g1_12dof.urdf <limit> elements (hip pitch/yaw 88 N·m @ 32 rad/s, hip roll & knee 139 N·m @ 20, ankles 50 N·m @ 37).
  • Armature / passive damping: the official MJCF’s joint defaults (armature="0.01", damping="0.001"); no frictionloss in the model.
  • Heights: measured by the converter’s FK — straight-leg pelvis 0.792 m (spawn), home-pose pelvis 0.784 m; the reward target uses unitree_rl_gym’s official base_height_target 0.78.

§Joint ordering

Canonical order is unitree_rl_gym’s DOF order (left leg root→foot, then right leg), so observations/actions — and an eventual ONNX export — line up with Unitree’s deployment convention.

unitree_g1_29dof
The Unitree G1 rev 1.0 full body (29-DOF model, 25 live joints): the same 12 leg actions as unitree_g1, but the waist (3), shoulders (3×2), elbows and wrist rolls are REAL PD-held joints instead of mass welded into the pelvis — the arms swing, react to pushes, and load the balance exactly as on hardware. This is the GR00T/HOVER-style body; the action space stays legs-only (Unitree’s own deployable walking convention).
unitree_g1_29dof_agile
unitree_g1_29dof (full body, 31 nv) with WBC-AGILE’s actuator parametrization — legs from unitree_g1_agile, upper-body holding gains from AGILE’s own waist/arm actuator groups (waist kp 300 / kd 5, shoulder_pitch 90/2, shoulder_roll 60/1, shoulder_yaw 20/0.4, elbow 60/1, wrist_roll 4/0.2; efforts per the model). The closest zealot gets to AGILE’s simulated robot: 31 vs 35 nv (wrist pitch/yaw welded for the 32-DOF solver cap).
