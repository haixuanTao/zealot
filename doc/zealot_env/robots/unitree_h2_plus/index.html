Module unitree_h2_plus

Expand description

The Unitree H2 Plus full-size humanoid (~1.8 m), as a legs-only 12-DOF walking platform.

Model: assets/robots/unitree_h2_plus_12dof.xml, generated by scripts/convert_unitree_biped.py from the official unitree_ros/robots/h2_plus/H2_Plus.urdf: the waist (3), head (2), arms (2×7) and hands (2×19) are welded into the pelvis (MuJoCo fusestatic, so mass + inertia compose exactly — 77.24 kg total, vs 32.1 kg for the G1), and every hinge axis is normalized to local +Z.

Numbers and their provenance:

  • Effort / velocity / position limits: the URDF <limit> elements (hips & knee 360 N·m @ 20 rad/s; ankle pitch 66.88 N·m @ 28.6; ankle roll only 19 N·m @ 100.7 — a fragile roll motor, lerobot-ankle-style).
  • PD gains: NO official RL config exists for the H2/H2 Plus (as of 2026-07), so these are the unitree_rl_gym G1 gains mass-scaled by 77.24/32.11 ≈ 2.4× on kp (√2.4 ≈ 1.55× on kd, keeping the damping ratio): hips 240/3, knee 360/6, ankle pitch 60/3 — except the 19 N·m ankle roll, which keeps the G1’s 40/2 (a stiffer kp would just bang-bang against the tiny torque clamp — see the lerobot ankle rationale). Treat as a starting point for tuning, not sysid truth.
  • Armature: not published; hips/knee get 0.05 (large rotors), ankles 0.01 (G1-class). Also a tuning starting point.
  • Default pose: the G1’s bent-knee home (hip_pitch −0.1, knee 0.3, ankle_pitch −0.2) — proportions are close enough that the same crouch works, giving base height 1.032 m (converter FK).
  • Heights: converter FK — straight-leg pelvis 1.039 m (spawn), home-pose pelvis 1.032 m (reward target).

§Joint ordering

Same canonical convention as the G1 (left leg root→foot, then right leg). NOTE the H2’s ankle chain is roll-THEN-pitch (knee → ankle_roll → ankle_pitch), the reverse of the G1 — so the FOOT link is *_ankle_pitch_link, and canonical order (which lists pitch before roll, matching the G1 convention) deliberately differs from chain order.
