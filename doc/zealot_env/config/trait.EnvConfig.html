Expand description

A task definition: implement once per (robot, task) pair.

The same EnvConfig is shared across all parallel environments. Only build_scene runs per-instance (at construction / reset); observe, act, reward and terminated run every step over the GPU readback.

Note: this single trait bundles the whole MDP for the first cut (like a Gym Env). It can later decompose into separate observation/reward/termination “manager terms” the way Isaac Lab does, if that proves useful.
