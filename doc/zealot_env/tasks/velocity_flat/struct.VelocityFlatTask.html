Expand description

The flat velocity-tracking task.

Fields§

§robot: RobotSpec

The robot spec (gains, default pose, limits, joint order).

§weights: RewardWeights

Reward term weights.

§stds: RewardStds

Tracking-kernel stds.

§sim_dt: f32

Physics timestep, s (200 Hz).

§decimation: u32

Control decimation (physics steps per control step).

§episode_s: f32

Episode length, s.

§tilt_limit: f32

Termination tilt limit, rad (base up-axis vs world up).

§min_base_height: f32

Termination floor on base height, m. Below this the episode ends — this is what stops the policy reward-hacking by sinking the (collider-less) torso through the ground while staying upright.

§step_relax_dist: f32

Cue distance under which the step-manoeuvre relaxation applies (m).

§step_std_base_h: f32

Widened base-height kernel while stepping (m).

§step_std_upright: f32

Widened upright kernel while stepping (rad).

§sym_yaw_gate: f32

|yaw_rate| at which the LATERAL half of bilateral_symmetry is fully released (BIPED_SYM_YAW_GATE; 0 = off, historical behaviour). See symmetry_error for why turning is otherwise taxed by that term.
