1//! Vectorized RL environment + MDP layer over the nexus GPU physics engine.
2//!
3//! # Getting started
4//!
5//! **Watch it walk first — nothing to install:** the
6//! [live demo](https://haixuantao.github.io/zealot/) is this training
7//! environment compiled to WebAssembly, stepping nexus GPU physics in your
8//! browser. Tap the ground and the robot walks there; switch engine tabs to
9//! step the same checkpoint through rapier.js and MuJoCo; load any published
10//! policy from the
11//! [Hugging Face repo](https://huggingface.co/haixuantao/zealot-g1-locomotion)
12//! by handle or URL.
13//!
14//! **Train the humanoid** (needs the
15//! [`cargo-gpu`](https://github.com/Rust-GPU/cargo-gpu) toolchain — see the
16//! [development guide](https://github.com/haixuanTao/zealot/blob/master/docs/development.md)):
17//!
18//! ```sh
19//! BIPED_ROBOT=g1_29dof_agile BIPED_CUTILE_GEMM=1 BIPED_TERRAIN=1 \
20//!   cargo run --release --example biped_train_gpu \
21//!   --features "gpu biped_gpu cutile" -- 50000 4096 my_policy.safetensors
22//! ```
23//!
24//! **Watch *your* policy walk:** upload the checkpoint to any Hugging Face
25//! repo and open
26//! `https://haixuantao.github.io/zealot/?ckpt=your-name/your-repo`.
27//!
28//! More: [getting started](https://github.com/haixuanTao/zealot/blob/master/docs/getting-started.md) ·
29//! [how it's built and why](https://github.com/haixuanTao/zealot/blob/master/docs/explanation.md) ·
30//! [benchmarks](https://github.com/haixuanTao/zealot/blob/master/docs/benchmarks.md)
31//!
32//! # Architecture
33//!
34//! This is zealot's "Isaac Lab tier": it wraps nexus's batched
35//! `GpuPhysicsPipeline` into a gym-style vectorized environment and provides
36//! the MDP managers. nexus already supports the primitives this needs
37//! (per-env reset today; motor-target writes and velocity readback after a
38//! ~10-line nexus patch).
39//!
40//! Modules:
41//! - `config` — the generic [`EnvConfig`] task interface (the MDP contract).
42//! - `math`   — dependency-free vec/quat helpers used by the MDP.
43//! - `obs_history` — per-env observation-frame stacking (`BIPED_OBS_HISTORY`).
44//! - `rng`    — a small deterministic LCG for command / domain sampling.
45//! - `robots` — robot asset specs (pure data): LeRobot bipedal, Unitree G1,
46//!               Unitree H2 Plus (select with `BIPED_ROBOT`).
47//! - `tasks`  — concrete task MDPs; currently flat velocity tracking.
48//!
49//! Planned (built incrementally):
50//! - `env`     — vectorized runtime: `reset()`, `step(actions) -> (obs, reward, done)`,
51//!               driving nexus's batched pipeline across all parallel environments.
